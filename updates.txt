1.2 Picture Model Purpose
The Picture Model is the UNIQUE component — it detects phishing purely through visual analysis of webpage screenshots. Its specific job:
•	Detect visual brand impersonation (fake PayPal, Google, bank login pages)
•	Analyze overall visual layout for suspicious patterns
•	Cannot be replaced by URL or text models — only vision can do this
•	OCR pipeline: if image contains text/URLs, extract and send to other models
•	QR pipeline: if image contains QR code, decode URL and send to URL model

model.classifier = nn.Sequential(
    nn.Dropout(p=0.35, inplace=True),
    nn.Linear(1536, 256),        # in_features=1536 for B3
    nn.ReLU(inplace=True),
    nn.Dropout(p=0.15),
    nn.Linear(256, 2)            # 2 classes: legitimate/phishing
)

4.3 Three-Phase Training Strategy
This is the most important part of the training approach:
Phase	Epochs	What Trains	Learning Rate	Purpose
Phase 1	0-9	Classifier head ONLY	LR_HEAD = 1e-3	Learn basic features without destroying pretrained weights
Phase 2	10-24	Last 4 blocks + head	LR_UNFREEZE = 5e-5	Gradually adapt deeper features to phishing patterns
Phase 3	25-60	Entire model (all layers)	LR_FINETUNE = 1e-5	Fine-tune everything very carefully

4.4 Loss Function
criterion = nn.CrossEntropyLoss(
    weight = loss_weights,        # [0.954, 1.054] — handles imbalance
    label_smoothing = 0.05        # prevents overconfidence
)
Loss weights calculated as: total / (2 * class_count) per class

4.5 Optimizer and Scheduler
optimizer = optim.AdamW(lr=cfg.LR_HEAD, weight_decay=1e-4)
scheduler = optim.lr_scheduler.ReduceLROnPlateau(
    optimizer, mode='max', factor=0.5, patience=5, min_lr=1e-7
)
Scheduler steps on Val F1 (not loss) — reduces LR by 50% if no F1 improvement for 5 epochs
